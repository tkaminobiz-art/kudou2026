Locally served WOFF2 subsets for this static site.

Zen Kaku Gothic New: body and section headings (400, 500, 700).
Noto Sans JP: the existing name mark (900), with regular and bold fallback faces (400, 700). Consent controls use the body typeface.
Montserrat: the existing Latin labels and numbers (700, 800).

Sources: https://github.com/google/fonts (official family folders: zenkakugothicnew, notosansjp, montserrat).
Each family is licensed under SIL Open Font License 1.1; the accompanying *-OFL.txt files are included.

Subsets cover the current site text, common kana and ASCII. System-font fallbacks cover other characters. Regenerate subsets when site copy changes to keep the same typeface for new characters.
